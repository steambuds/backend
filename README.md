# Readme
## Setup the repo on VPS manually
### install mise by 
```bash
curl https://mise.run | sh
```
### activate mise 

```bash
echo 'eval "$(~/.local/bin/mise activate bash)"' >> ~/.bashrc
```
then source
```bash
source ~/.bashrc
```

### install ruby
```bash
mise install ruby@[version]
```
### get the repo on the vps
use github or rsync

### set environement variables 
```bash
echo 
```
